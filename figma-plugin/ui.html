Having trouble connecting?

Plugin installation does not start the bridge. Restart/reload your coding agent (Pi: /reload), confirm Flutter Fidelity MCP loads without an error (Pi: /mcp), then ask it to start the bridge and give you a fresh pairing code. Figma and the agent must run on this computer. Allow local network access if prompted; do not disable browser security or add a proxy. A missing reply can mean a stopped bridge or blocked network access. If Figma does not finish loading, close and rerun this plugin.

Keep this plugin and file open. Only requested frames are exported to this computer. No Figma access token or proxy is needed.
