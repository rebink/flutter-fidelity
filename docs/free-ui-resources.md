# No-attribution UI reference options

License checks performed 12 October 2026 against the product's own page.
These are candidates for future examples; they are not the source of the bundled
wellness designs. Verify the downloaded package's license and any included
fonts/photos separately before importing assets.

| Kit | Available complexity | Verified license statement |
| --- | --- | --- |
| [Bloo](https://bloouikit.com/) | 250+ components, 150+ mobile screens, dark mode and flowcharts; suitable for multi-screen applications | Product page explicitly states CC0 for personal/commercial use |
| [Contra](https://contrauikit.com/) | 150+ components and 50+ mobile screens, product cards, profiles, lists and chart screens | Product page explicitly states CC0 for personal/commercial use |
| [UI Pack](https://kenney.nl/assets/ui-pack) | 430 reusable UI assets; useful for composing complex interactive screens rather than a finished mobile dashboard | Asset page states CC0; [usage FAQ](https://kenney.nl/support) explicitly says attribution is not required |

CC0 removes an attribution requirement for the covered work. It does not grant
rights in unrelated trademarks or guarantee the licensing of separately bundled
third-party assets. Keep required dependency/font notices even when no UI-designer
credit is necessary.

The bundled Open Wellness designs are original controlled examples with a CC0
public-domain dedication. They avoid third-party design references entirely and
provide editable design sources alongside independently implemented Flutter UI.
